# 00 术语与口径（全项目统一）

> 本项目的讲稿、PPT、报告、看板、指标字典、SQL 题库都按本文的名称和定义书写：**一个概念只有一个名称，一个名称只有一个定义**。
> `tests/test_terminology.py` 会自动检查所有产出中是否出现了第 6 节列出的"不再使用的叫法"。

## 1. 核心概念：品质客诉率

本项目的全部内容（指标体系、看板、专题分析、SQL 取数）都围绕一个指标展开：

> **品质客诉率**：签收订单中，用户因商品本身的问题给出 1-3 星、并在评价文字里描述了该问题的订单所占的比例。

```
品质客诉率 = 品质客诉订单数 ÷ 签收订单数        （分子、分母按同一下单月归属）
```

## 2. 核心概念拆解（逐层拆到不能再拆的词元）

```
品质客诉率
├─ 品质客诉订单数：品质客诉订单的个数
│   └─ 品质客诉订单 = 同时满足以下三个条件的订单
│        ├─ ① 是签收订单
│        │     └─ 签收订单 = 订单状态为"已签收"（delivered）且签收时间不为空的订单
│        ├─ ② 最后一次评价的评分为 1-3 星
│        │     ├─ 评价 = 用户对一个订单提交的一次打分（1-5 星），可附文字
│        │     └─ 最后一次评价 = 同一订单有多条评价时，提交时间最晚的一条
│        └─ ③ 最后一次评价的文字命中至少一个品质问题标签
│              └─ 品质问题标签 = 用葡语关键词规则从评价文字中识别出的 5 类问题（一条评价可同时命中多类）
│                   ├─ 假货：用户反馈商品非正品、仿冒或非原装
│                   ├─ 质量缺陷：用户反馈商品损坏、功能故障、做工差或临期过期
│                   ├─ 货不对板：用户反馈错发，或颜色、尺码、型号、材质与商品描述不符
│                   ├─ 少件漏发：用户反馈少发、漏发、缺配件或只收到部分商品
│                   └─ 包装破损：用户反馈外包装破损、被拆开或没有防护
├─ 签收订单数：签收订单的个数
└─ 下单月：订单下单时间所在的自然月
      └─ 按下单月归属 = 一个订单的分子、分母都记在它的下单月，保证分子和分母是同一批订单
```

## 3. 指标层级

| 层级 | 含义 | 本项目的指标 |
|---|---|---|
| 核心指标 | 衡量品控结果、用于考核的唯一指标 | 品质客诉率 |
| 结果指标 | 核心指标按问题类型拆开后的指标 | 少件漏发客诉率、质量缺陷客诉率、货不对板客诉率、假货客诉率、包装破损客诉率、品质退货率（待接入） |
| 体验指标 | 反映用户整体体验、受物流和服务影响、不用于考核品控的指标 | 差评率、平均评分、5 星好评率、差评品质原因占比 |
| 过程指标 | 在用户签收之前就能观测、会影响结果指标的指标 | 商品准入、商家管理、仓配履约、待接入四类（见指标字典） |

## 4. 术语表

每个术语的定义只使用本表中已经定义过的词。

### 4.1 订单与评价

| 术语 | 定义 |
|---|---|
| 订单 | 数据集中的一个订单（order_id） |
| 签收订单 | 订单状态为"已签收"（delivered）且签收时间不为空的订单 |
| 下单月 | 订单下单时间所在的自然月 |
| 评价 | 用户对一个订单提交的一次打分（1-5 星），可附文字 |
| 评价日期 | 最后一次评价的提交日期 |
| 评价回收率 | 有评价的签收订单数 ÷ 签收订单数；用来判断最近月份的评价是否已经收齐 |
| 最后一次评价 | 同一订单有多条评价时，提交时间最晚的一条；所有指标只使用最后一次评价 |
| 差评 | 最后一次评价为 1-2 星 |
| GMV | 订单中商品售价之和（不含运费） |
| 件数 | 订单包含的商品行数；同一商品买 2 件计为 2 |
| 单件订单 | 件数为 1 的签收订单 |
| 多件订单 | 件数不少于 2 的签收订单，分为同 SKU 多件、单商家多 SKU、多商家三类 |
| 承诺送达日期 | 平台在下单时告知用户的预计送达日期 |
| 主商品 | 订单中单价最高的商品（单价相同时取商品行序号最小的） |
| 主品类 / 主商家 | 主商品所属的品类 / 商家；按品类或商家汇总订单级指标时，一个订单只归到它的主品类或主商家 |
| 品类 | 商品所属的品类，共 73 个（如电脑配件、钟表礼品、女装），由葡语品类名翻译而来 |
| 一级类目 | 把 73 个品类归并成的 13 个大类（如 3C数码、服饰鞋包、家居家纺、钟表与潮流好物）；商品缺少品类信息时记为"未知" |
| 订单宽表 | 每个订单一行、汇总订单、商品、评价和标签信息的明细表（dwd_qc_order）；看板、报告、SQL 取数的指标都从这张表计算 |
| 数据校验 | 每次运行自动执行的 18 项检查（跨层对账、主键唯一、分子不大于分母等），任一项不通过就不输出结果 |
| 预警清单 | 看板第一屏的三类预警：控制图越限的月份、品质客诉率连续 3 个月上升的主品类、按评价日期连续 3 天及以上每天都有品质客诉订单的商家 |

### 4.2 标签

| 术语 | 定义 |
|---|---|
| 品质问题标签 | 见第 2 节：假货、质量缺陷、货不对板、少件漏发、包装破损 5 类 |
| 履约服务标签 | 未收到货、物流延迟、服务售后 3 类；不计入品质客诉 |
| 主标签 | 一条 1-3 星评价命中多个标签时，按优先级取第一个：假货 > 质量缺陷 > 货不对板 > 少件漏发 > 包装破损 > 未收到货 > 物流延迟 > 服务售后；一个标签都没命中的 1-2 星评价，按有无文字记为"未命中标签差评"或"无文字差评" |
| 标注样本 | 从"签收订单、最后一次评价 1-3 星、有文字"的 12,780 条评价中随机抽取的 200 条；由大模型逐条阅读葡语原文给出真实标签（判定时不看规则结果），每条附中文释义供人工抽查 |
| 标签精确率 | 规则判为品质问题、且标注样本也判为品质问题的评价数 ÷ 规则判为品质问题的评价数 |
| 标签召回率 | 规则判为品质问题、且标注样本也判为品质问题的评价数 ÷ 标注样本判为品质问题的评价数 |

### 4.3 指标

| 术语 | 定义（公式） |
|---|---|
| 品质客诉订单 | 见第 2 节 |
| 少件漏发客诉订单（质量缺陷、货不对板、假货、包装破损客诉订单同理） | 命中少件漏发标签的品质客诉订单 |
| 品质客诉率 | 品质客诉订单数 ÷ 签收订单数 |
| 少件漏发客诉率（质量缺陷客诉率、货不对板客诉率、包装破损客诉率同理） | 少件漏发客诉订单数 ÷ 签收订单数 |
| 假货客诉率 | 假货客诉订单数 ÷ 签收订单数，以"单/万单"表示（每 1 万个签收订单中的个数） |
| 未收到货客诉率 | 最后一次评价 1-3 星且命中未收到货标签的订单数 ÷ 订单数（不限是否签收）；属于过程指标，不计入品质客诉率 |
| 差评率 | 最后一次评价为差评的订单数 ÷ 有评价的订单数（不限是否签收） |
| 差评品质原因占比 | 最后一次评价为差评的订单中，主标签属于品质问题标签的订单所占比例（分母含无文字的差评） |
| 准时签收率 | 签收日期不晚于承诺送达日期的签收订单数 ÷ 签收订单数 |
| 发货超时率 | 商家把商品交给物流的时间晚于平台规定发货时限（shipping_limit_date）的订单数 ÷ 已发货订单数 |
| 多件订单占比 | 多件订单数 ÷ 签收订单数 |
| 多件订单少件漏发客诉率 | 多件订单中命中少件漏发标签的品质客诉订单数 ÷ 多件订单数 |

### 4.4 商家分层

| 术语 | 定义 |
|---|---|
| 商家评估窗口 | 下单月为 2018-03 至 2018-08 的 6 个月 |
| 商家签收订单 | 包含该商家商品的签收订单；一个订单含多个商家时，每个商家各计 1 单 |
| 商家品质客诉订单 | 包含该商家商品的品质客诉订单；计法同上 |
| 参评商家 | 商家评估窗口内商家签收订单不少于 30 单的商家（共 299 家） |
| 商家基准品质客诉率 | 商家评估窗口内全部商家的商家品质客诉订单之和 ÷ 商家签收订单之和（一个订单含多个商家时重复计入，所以不等于平台的品质客诉率） |
| 商家基准差评率 | 商家评估窗口内全部商家的差评订单之和 ÷ 有评价订单之和（计法同上） |
| 平滑品质客诉率 | （商家品质客诉订单数 + 50 × 商家基准品质客诉率）÷（商家签收订单数 + 50）；即贝叶斯平滑，让单量少的商家向基准靠拢 |
| 高风险商家 | 参评商家中，平滑品质客诉率 ≥ 商家基准品质客诉率 × 2，且商家品质客诉订单不少于 3 单 |
| 需关注商家 | 参评商家中不属于高风险商家，且平滑品质客诉率 ≥ 商家基准品质客诉率 × 1.5 或差评率 ≥ 商家基准差评率 × 1.5 |
| 正常商家 | 其余参评商家 |
| 商家品质分 | 参评商家的 0-100 分综合得分：品质客诉率占 50%、差评率 20%、发货超时率 15%、准时签收率 15%，每项按该商家在参评商家中的百分位排名打分；只用于商家之间排序 |
| 回测 | 用一个 6 个月窗口（训练期）给商家分层，再计算同一批商家在紧接着的 6 个月（检验期、商家签收订单不少于 30 单）的品质客诉率 ÷ 检验期的商家基准品质客诉率；共 3 组窗口，结果按商家数加权平均 |

### 4.5 统计方法

| 术语 | 定义 |
|---|---|
| 因素分解 | 两期品质客诉率之差 = 结构效应 + 组内效应 + 交互项，按一级类目拆分 |
| 结构效应 | Σ（各一级类目签收订单占比的变化 × 基期该类目品质客诉率）；衡量"卖的品类变了"带来的变化 |
| 组内效应 | Σ（基期各一级类目签收订单占比 × 该类目品质客诉率的变化）；衡量"同一类目自身变差"带来的变化 |
| 交互项 | Σ（占比的变化 × 品质客诉率的变化） |
| 控制图 | 按月画品质客诉率的 p 控制图 |
| 中心线 | 2017 年全年的品质客诉率 |
| 上控制限 / 下控制限 | 中心线 ± 3 × √（中心线 × (1 − 中心线) ÷ 当月签收订单数） |
| 越限 | 当月品质客诉率高于上控制限 |
| 持续偏移 | 连续 9 个及以上月份落在中心线同一侧 |
| 两比例 z 检验 | 检验两期品质客诉率之差是否超出随机波动；p 值 < 0.05 视为显著 |
| 95% 置信区间 | 按 Wilson 方法计算的比例区间 |

### 4.6 治理测算与抽检

| 术语 | 定义 |
|---|---|
| 治理测算 | 以 2018 年 1-8 月的签收订单为基期，估算三项举措实施后的品质客诉率；一个品质客诉订单被多项举措覆盖时，避免概率按 1 − Π(1 − 各举措降幅) 叠加 |
| 举措 A | 多件订单出库复核 + 分包裹提醒；作用对象：多件订单中命中少件漏发标签的品质客诉订单 |
| 举措 B | 高风险商家和需关注商家整改；作用对象：主商家为高风险商家或需关注商家的品质客诉订单 |
| 举措 C | 一级类目 3C数码、钟表与潮流好物的正品与商品描述专项；作用对象：主品类属于这两个一级类目、且命中假货或货不对板标签的品质客诉订单 |
| 情景 | 举措降幅的三组假设：悲观（A 30%、B 15%、C 15%）、中性（50%、30%、30%）、乐观（70%、45%、45%） |
| 入仓类问题订单 | 命中质量缺陷、货不对板或假货标签的品质客诉订单（入仓质检能拦截的问题） |
| 出库类问题订单 | 命中少件漏发标签的品质客诉订单（出库复核能拦截的问题） |
| 风险分 | 用 2017-09 至 2018-02 的签收订单计算。入仓类问题率 = 入仓类问题订单数 ÷ 签收订单数。商家风险分 = 主商家的平滑入仓类问题率（平滑方法同平滑品质客诉率，加 50 单基准）；商家 × 品类风险分 = 商家风险分 × 主品类的平滑入仓类问题率（加 200 单基准）÷ 全部签收订单的入仓类问题率。出库复核不用风险分，按"多件订单优先、其余随机"排序 |
| 抽检比例 | 抽检的签收订单数 ÷ 全部签收订单数 |
| 问题订单覆盖率 | 按风险分从高到低抽检一定比例的签收订单时，抽到的问题订单数 ÷ 全部问题订单数；在 2018-03 至 2018-08 的签收订单上计算（样本外检验）；风险分相同时按固定种子的随机顺序 |
| 增益曲线 | 横轴为抽检比例、纵轴为问题订单覆盖率的曲线；越靠左上说明风险分越能把问题订单排在前面 |
| 穿戴类 | 主品类属于一级类目"服饰鞋包"（箱包配饰、鞋靴、运动服饰、女装、男装、内衣泳装、旅行箱包），或主品类为"钟表礼品""童装"的签收订单 |
| 品类结构重加权 | 把穿戴类在签收订单中的占比从 9.2% 调为 75%，其余 25% 为非穿戴类，用两类各自 2018 年 1-8 月的指标加权重算整体指标；75% 取自唯品会 2024 年财报报道的穿戴类 GMV 占比，这里用 GMV 占比近似订单占比 |

## 5. 数字格式

| 数字类型 | 格式 | 示例 |
|---|---|---|
| 品质客诉率与 5 个结果指标（假货客诉率除外） | 百分比，保留 2 位小数 | 5.00% |
| 假货客诉率 | 单/万单，保留 1 位小数 | 22.0 单/万单 |
| 其他比率与占比（差评率、准时签收率、占比、精确率、召回率、覆盖率） | 百分比，保留 1 位小数 | 33.6% |
| 百分点 | 保留 2 位小数，写作 pp | +0.74pp |
| 倍数 | 保留 1 位小数 | 2.2 倍 |
| z 值 | 保留 2 位小数 | z = 5.05 |
| p 值 | 小于 0.0001 时写"p < 0.0001"，小于 0.01 时写"p < 0.01"，否则保留 2 位小数 | p = 0.09 |
| 订单数、商家数 | 整数，千分位 | 96,203 |
